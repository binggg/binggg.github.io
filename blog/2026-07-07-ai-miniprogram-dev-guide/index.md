说实话，我很少觉得一个"福利"值得专门写文章。但这次不太一样。

2026 年 7 月，三件事撞在同一个时间点：

- 微信开发者工具开放了 **AI 智能体 Skills**，你用的 Cursor、Claude Code 能直接读开发者工具的控制台日志、看模拟器截图、自动部署云函数。
- **小程序成长计划第二期加码**，Token 从 1 亿提到 10 亿，生图从 1 万张到 10 万张，模型升级混元 Hy3。
- **CloudBase 把后端底座摊平了**，AI 工具直接接它的大模型，Token 从套餐里扣，写完直接上线。

这三件事放一起，"一个人独立做个完整小程序"最难的几个坎，全被打通了。下面是我的实操笔记，每步都走过，好坏都直说。

## 注册账号：卡我十分钟的是 AppID

去 [mp.weixin.qq.com](https://mp.weixin.qq.com) 注册小程序账号，个人主体就行。

注册完顺手把 **AppID** 复制出来——在「开发 > 开发管理 > 开发设置」里。后面每一步都要用它，我当时没记，后面反复翻回去查，麻烦。建议现在就记到备忘录。

## 领成长计划资源包：这一步真值钱

登录微信公众平台，左侧菜单 → **行业能力 → 小程序成长计划**，点「参与计划」，填个简介和来源（来源我填的「朋友邀请」，秒过）。

报名成功后点「领取」，10 亿 Token + 10 万张生图额度马上到账。按官方 API 价格折算，这两样值两万多块。

几个关键信息，别踩：

- 资源包 **6 个月有效**，一个账号只能领一次
- 第一期报过名的，**系统自动补发**，不用重新申请
- 没有云开发环境的送 **6 个月个人版**，有了的领 **120 元代金券**
- 用量到 80%、90%、100% 公众号会提醒

小游戏也能领，入口在「功能 > 游戏能力地图 > AI 成长计划」。我没做小游戏，这个没实测，以官方页面为准。

## 装开发者工具：版本必须够新

下载 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)。

要玩 AI 智能体 Skills，必须装 **预览版 2.02.2607032 或以上**。我一开始装了稳定版，怎么都找不到 Skills 入口，翻文档才发现版本要求。白折腾半小时。

## 把 AI 工具接上 CloudBase：这是体验最好的部分

你的 Cursor、CodeBuddy、Claude Code 可以直接连 CloudBase 的大模型，Token 从套餐里扣，不用额外买 API Key。

控制台拿到环境 ID（`ENV_ID`），然后在 AI 工具里配置：

| 配置项 | 值 |
|---|---|
| Base URL | `https://<ENV_ID>.api.tcloudbasegateway.com/v1/ai/cloudbase` |
| API Key | 云开发的 API Key |
| 模型 | `hy3`（或其他已开启的模型） |

各工具入口不一样，原理相同：

- **CodeBuddy**：设置 → 添加自定义模型 → Provider 选 OpenAI Compatible
- **Cursor**：设置 → Models → OpenAI API Key 填 CloudBase 的 Key，Override Base URL 填上面的 URL
- **Claude Code**：设两个环境变量 `ANTHROPIC_BASE_URL` 和 `ANTHROPIC_AUTH_TOKEN`

支持的模型有混元、DeepSeek、GLM、Kimi、MiniMax，都在同一个套餐池子里。

## 真正让我兴奋的：AI 智能体 Skills

### 以前的问题

你的 AI 编程工具能读写代码、能跑命令行，但开发者工具里的世界它看不见——编译过了没、模拟器长什么样、控制台报了啥错、云函数部署好了没。它像个顶级厨师，菜谱背得滚瓜烂熟，但看不见锅、闻不到味，你只能一遍遍试吃。

### 四个场景我觉得最有感觉

**云函数报错了** → AI 直接读控制台日志和网络请求记录，定位到具体代码行，自己修。不用你复制粘贴。

**界面写完了要验收** → AI 自动编译、操作模拟器、截图检查布局。文案错位、样式跑偏，它自己发现自己改。

**说一句「帮我做个每日诗文小程序」** → AI 从写代码到编译验证到推真机预览，全自动。你扫个码就看效果。

**自己截图分析布局** → 按钮位置、间距、颜色，它截完图自己审一遍。

### 安全方面

云函数部署、体验版发布这些危险操作，会弹窗让你确认。AppID、云环境这类敏感信息，也要授权才能拿。所有操作都在本地，代码和日志不上传。

### 怎么接

装预览版，然后二选一：

- 终端跑 `wechatide`，把输出的 Skill 路径贴给你的 AI 工具
- 开发者工具菜单 → 「导出开发者工具 Skill」→ 导入 AI 工具

## 实战：做个「每日诗文」小程序

拿真实案例走一遍，感受一下体感。

**第一步：让 AI 生成项目。** 在接好 CloudBase 的 AI 工具里输入：

```
创建一个微信小程序「每日诗文」。
首页展示一句诗文 + 作者 + 白话翻译。
底部 TabBar 有首页和关于两个页面。
数据从云开发数据库读。浅色干净风格。
```

AI 会吐出 `app.json`、页面代码这些基本功架。我拿到手先扫了一遍结构，命名规范，没乱起文件。

**第二步：配云开发环境。** 开发者工具点「云开发」，选你的环境（或者直接用成长计划送的那个）。新建一个 `poems` 集合，塞一条数据：

```json
{
  "title": "静夜思",
  "author": "李白",
  "content": "床前明月光，疑是地上霜。举头望明月，低头思故乡。",
  "translation": "明亮的月光洒在床前，像是地上的白霜。"
}
```

**第三步：让 AI 写云函数 + 前端。** 让它生成一个云函数，从集合里随机取一条诗文返回，同时在首页调用并渲染：

```javascript
exports.main = async (event, context) => {
  const { data } = await db.collection('poems')
    .aggregate().sample({ size: 1 }).end()
  return { code: 0, data: data[0] }
}
```

云函数右键「上传并部署」。接了 AI 智能体 Skills 的话，让 AI 自己部署就行。

**第四步：预览调试。** 开发者工具点「预览」，微信扫码看效果。遇到报错，接 Skills 就一句话「帮我看这个报错」，它自己读日志、定位、修；没接就把错误贴给 AI，也能修。

## 部署上线：提审前让 AI 过一遍

开发者工具上传 → 小程序管理后台的「管理 > 版本管理」提交审核，通常 1-3 个工作日。

**一个提醒**：AI 生成的代码经常漏隐私政策、用户协议这些非功能性要求。我第一次提审就被拒，就是因为没写隐私政策。提交前让 AI 帮你过一遍：

```
帮我检查这个小程序是否符合审核规范：
- 有用户协议和隐私政策吗
- 页面有加载状态和错误提示吗
- 云函数有权限控制吗
- 符合所选类目的服务范围吗
```

## 为什么我觉得现在是最好时机

**钱的事：**

| 项目 | 以前 | 现在 |
|---|---|---|
| AI 编程 | Cursor $20/月 | CloudBase 套餐含 Token |
| 后端 | 服务器 50+/月 | 云开发免费 6 个月 |
| AI 模型 | API 按量付费 | 10 亿 Token + 10 万张生图免费 |
| 支付 | 自己开发 | 全终端虚拟支付 + 优惠费率 |

**时间的事：** 以前写一个带后端的小程序 5-7 天。现在 AI 辅助，2-3 小时出原型，1-2 天能提审。调试也从「复制粘贴报错」变成「AI 自己查日志、定位、修」。

**数据的事：** 成长计划已经有 4.5 万个小程序接入，70% 以上是个人开发者。作业辅助、游戏攻略、证件照生成、配音工具……各垂直方向都有跑到十万级日活的产品。这个数字是官方口径，来源见文末链接。

微信生态的社交传播 + 虚拟支付 + 免开发广告接入，让「做出来 → 有人用 → 能变现」这条链路短了很多。

## 几个实操提醒

- **模型会下线**。我文章里写的 `hy3` 是当下推荐模型，但模型名会变。动手前先去控制台「AI → 生文模型」看当前支持哪些，别照抄旧教程的模型名。
- **Token 用完可以转资源点套餐**。套餐用量可以抵扣大模型 Token，DeepSeek、混元、GLM、Kimi、MiniMax 都走同一个池子。
- **一个账号只能领一次**。练手用完额度了，注册个新小程序号接着领。
